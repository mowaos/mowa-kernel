# Security policy

The kernel's purpose is to produce decisions and audit records that can be verified.
A bug that lets two parties compute different hashes from the same inputs, or lets a
record be altered without breaking the hash chain, is a security issue.

## Reporting a vulnerability

Please report privately through GitHub's **Report a vulnerability** button on the
repository's Security tab. Do not open a public issue.

Include the affected version, the inputs that reproduce the problem, and what you
expected to happen. You will get an acknowledgement within 7 days.

## Supported versions

Only the latest release receives fixes before 1.0.
